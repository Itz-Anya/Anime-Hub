## ✨ Overview

Anime Hub is a React single-page app for browsing trending, seasonal, and top-rated anime, searching the entire catalog, and keeping a personal watchlist — all stored locally in your browser. It's a Create React App port of the original TanStack Start project.

## 🚀 Features

- **Discover** — trending, top-rated, seasonal, and upcoming anime curated on one home feed
- **Waifu of the Day** and rotating anime quotes on the home page
- **Advanced Search** — filter by type, status, rating, and genre, with a `⌘K` / `Ctrl+K` shortcut
- **Anime & Character Details** — synopsis, studios, genres, trailers, and more
- **Personal Watchlist** — track progress across Watching, Completed, Plan, Dropped, and On Hold
- **Favorites & Recently Viewed** — saved locally, no login required
- **Responsive UI** — polished dark theme with glassmorphism, smooth animations, and a mobile bottom nav
- **Toast notifications** for a smooth, app-like feel

## 🛠️ Tech Stack

- **React 18** + **Create React App**
- **TypeScript**
- **React Router DOM** — client-side routing
- **TanStack Query** + **Axios** — data fetching & caching
- **Tailwind CSS** — custom OKLCH color palette
- **Jikan API (MyAnimeList)** — anime & character data
- **AniList GraphQL API** — trailer lookups
- **lucide-react** — icons
- **sonner** — toast notifications

## 📦 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
git clone https://github.com/itz-Anya/Anime-Hub.git
cd Anime-Hub
npm install
```

### Environment Variables (optional)

Create a `.env` file in the project root to customize branding:

```env
REACT_APP_SITE_NAME=Anime Hub
REACT_APP_SITE_URL=https://your-domain.com
REACT_APP_SITE_IMAGE=https://your-logo-url.png
```

### Run the app

```bash
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### Build for production

```bash
npm run build
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl/⌘ + K` | Jump to Search |

## 🌐 Data Sources

This project uses the free, public [Jikan API](https://jikan.moe/) (unofficial MyAnimeList API) and the [AniList GraphQL API](https://anilist.co/) for anime data, images, and trailers. No API key required.

## 💾 Local Storage & Privacy

Anime Hub doesn't use accounts or a backend database. Your watchlist, favorites, and recently viewed history are stored entirely in your browser's local storage — private by design.
